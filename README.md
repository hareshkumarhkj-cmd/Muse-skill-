# Rays of Sanatan — Muse handoff

[Download the complete project ZIP](./rays-stone-test.zip?raw=true).

- Topic: Pattharon Ka Santulan — original fictional temple visual test.
- Duration: 15 seconds. Size: 1080x1920. Frame rate: 30fps.
- Composition: `RaysShort01` (one composition).
- Audio: silent; no voiceover, music or SFX.

Extract the ZIP, enter `rays-stone-test`, then run:

```sh
npm install
npx remotion render
```

Output: `out/rays-stone-test.mp4`.

Installation, TypeScript checking, full 450-frame rendering and composition
listing passed on the preparation host. Detailed results and full earlier
error logs are included in `TEST-NOTE.txt` and `validation/` inside the ZIP.
This has not been tested in Muse itself.

The ZIP includes code, pinned dependencies/lockfile, three original AI still
images and a bundled Hindi font. It excludes installed dependencies, Git
metadata and render outputs. No keys or manual media downloads are required.
Node/npm and browser-compatible host libraries are runtime prerequisites.

This is a still-image camera-animation proof. It does not reproduce the
reference's moving characters, physical simulations or audio. The architecture
is fictional and no supplied reference imagery/audio is included.
