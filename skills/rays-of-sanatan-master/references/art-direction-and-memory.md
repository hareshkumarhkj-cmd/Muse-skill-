# Art direction, critique and reusable learning

Original Rays adaptation informed by BeyondArtist's strategy, artist handoff,
critique and memory system. See the source review and third-party notices.

## Two responsibilities, one coherent result

Act as a communication designer AND an artist. The designer establishes the
truthful promise, viewer question, reading order, exact copy and constraints.
The artist challenges generic ideas and resolves subject treatment, gesture,
scale, material, composition and light. If real agents are available, delegate
independent review with a written handoff; otherwise perform both passes
sequentially. Do not claim a team ran when it did not.

Before expensive generation consider two or three inexpensive concepts
internally, not three finished videos. Select ONE according to the brief.
Do not impose extra variants, scenes or cost on a one-test request.

For each significant reference observation write:

> inspected source → visual mechanism → fit for this story →
> original Rays decision → visible output check.

Example: immense stone beside tiny workers → scale contrast → makes weight
legible → fictional pillar/blue scale figures, not copied reference frame →
check whether the object reads instantly on a phone without the caption.

“Use cinematic lighting” is insufficient. Say where light falls, what the eye
should read first/second, what the caption adds and what to remove. Compare
palette/layout alternatives only when choices are open; don't override approved
brand colors or a bounded correction.

## Designer handoff to artist/editor

Provide: viewer promise; one-line concept; factual/fiction status; subject
locks; shot roles and frame ranges; first/second read; light/material/palette
roles; exact Hindi line breaks; exclusions; motion mode; allowed freedom;
reference-to-decision record; actual acceptance checks.

The artist can improve the idea inside the truthful message and user constraints.
Stronger does not always mean brighter, busier or more detailed. Reject a sharp
image if meaning is unclear, medium inconsistent or hierarchy wrong.

## Two-pass critique

Designer: understandable, truthful, specific question and answer? Do image/caption
support the same idea? Is the scene necessary? Read at phone size.

Artist: believable light/material, depth, gesture, anatomy/architecture,
identity and art-form consistency. Repair actual output rather than renaming
a failed image “experimental” after the fact. Re-inspect after repair.

## Memory without pretending to train models

Keep episode-local DECISIONS.md and an optional compact channel bible in
user-controlled storage. Record approved vs draft vs rejected separately:
subject locks, working prompts, pronunciations, timing lessons, actual feedback.
Never turn a rejected image into the default channel style.

Retrieve relevant notes before asking known questions. Preserve provenance,
date and task scope. If durable storage is absent, deliver notes for the user
to carry forward; do not promise background capture, cross-account memory or
automatic syncing. This is instruction/data reuse, not model training.
Never bundle private photos, recordings, account settings or other clients'
memory in the portable skill.

Real analytics can test a hook. Taste, view counts or invented scores cannot
establish CTR, virality or viewers' motives.
