# Rays of Sanatan — master skill

Portable production instructions for original cinematic Hindi Shorts:
research, scripting, art direction, image/motion planning, voiceover, editing,
Remotion engineering and evidence-based QC.

Start with [START-HERE.md](START-HERE.md), then [SKILL.md](SKILL.md).
Read [source comparison](references/source-review.md),
[actual validation](VALIDATION.md) and [rights/attribution](THIRD-PARTY.md).

Includes Python 3.10+ stdlib checkers and a complete 15-second silent
Remotion example. The skill itself needs no API key; generating voice/images
depends on the host's real authorized tools. It neither installs models nor
guarantees Muse or another platform has the required capabilities.
